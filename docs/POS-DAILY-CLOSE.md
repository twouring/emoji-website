# POS 日結／關帳

後台與 POS 共用「日結」頁。營業日仍以台北時間凌晨 03:00 起算；在咖啡／三點水分品牌記帳，但共用一個錢櫃，同一時間只開一本帳。

1. **先看當日營收**：確認日期、品牌、訂單總額。作廢不計、折扣後的訂單營收不會因手填對帳數字而改動。
2. 按「關帳」，**清點錢櫃**：按面額填張數或直接填總額；填留存金。現金有短溢時，填「現金差異原因」，再勾已確認。
3. **LINE Pay → 信用卡 → 轉帳與其他帳戶**：依序填本品牌實收，有差異逐項填原因，再逐項確認。沒有收款也要填 `0`，不能留白。啟用的自訂收款帳戶、當天有營收的停用帳戶也會列出。
4. **最後核對總額**：帳戶總額＝現金實收＋各非現金帳戶實收。現金實收＝點鈔－開帳零用金－臨時收入＋臨時支出，並不是整個錢櫃金額。
5. 訂單總額與帳戶總額相同，可直接按「確認關帳」；不同也不必再填原因（各帳戶差異原因已在逐項核對填過）。即使個別差異正負互抵、總額相同，各項差異原因也不能省略。

變更已確認的金額或原因，該項與後續項目會取消確認。頁面自行重新載入相同資料時保留記憶體草稿；營收或帳戶變更時保留輸入、但清除確認，須重新核對。重新整理瀏覽器後不保證保留草稿。

## 各帳戶確認（小結／關帳前）

日結頁「開關帳」上方列出開帳中品牌的每個帳戶（現金、LINE Pay、信用卡、轉帳與其他），各有一顆「核對」按鈕：

- **現金**：應收＝應有現金（零用金＋現金營收＋臨時收支）；實收按面額填張數或直接填總額。
- **LINE Pay**：實收自動帶入後台同步結果（依開關帳時間歸屬本店別），可修改；尚未同步時提示先按「同步 LINE Pay」。
- **信用卡、轉帳與其他**：對照收單機或後台手填；沒有收款填 `0`。

應收≠實收時必須填差異原因才能按「確認」。確認結果只留在本頁記憶體（換營業日或重新整理即清除），不寫入帳務；按「關帳」時會自動帶入點鈔面額、各帳戶實收與原因，關帳流程的逐項確認仍須重新勾選。

## 全店參考不是本品牌帳戶

下方「帳務參考（另行逐項確認）」保留 LINE Pay 同步、店別歸屬、分店明細、CSV、台新手填紀錄與儲存功能。LINE Pay 依當天開關帳時間歸屬店別；台新手填紀錄涵蓋全店。參考資料不會自動視為已確認，請對照商家後台、機台紀錄或交接資料，分品牌填入上方關帳流程。實收以退款扣除後、手續費扣除前核對。

## 既有功能與歷史紀錄

- 開帳、零用金承接、臨時收支、小結點驗、印小結單、管理員重開補單均保留。
- 新關帳單會保存並列印各帳戶 POS／實收／差額／原因，以及訂單總額、帳戶總額、總差異與總差異原因。重印使用關帳當時凍結的 JSON，不重算。
- 舊關帳單仍能重印，但不補造舊資料沒有的確認與原因。
- 舊版客戶端只送現金的關帳請求會被拒絕；請重新載入 POS 頁面。

## 驗證

```sh
node --test scripts/test-*.mjs
CHROME_PATH=/path/to/chrome node scripts/smoke-pos-daily-close.mjs
CHROME_PATH=/path/to/chrome node scripts/smoke-pos-account-confirm.mjs
```

瀏覽器 smoke 使用固定的本機模擬資料，實際執行表單渲染、逐項確認、送出 payload、純邏輯驗證與列印 HTML；不會呼叫正式環境或建立財務紀錄。正式環境僅以 GET 與部署映像版本驗證；實際帳務入庫、機台實收及紙本列印仍須現場操作驗收。
