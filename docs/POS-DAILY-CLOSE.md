# POS 日結／關帳

後台與 POS 共用「日結」頁。營業日以台北時間凌晨 03:00 起算；在咖啡／三點水分品牌記帳，共用一個錢櫃，同一時間只開一本帳。

關帳分兩段：先在上方「01 核對帳戶」把每個帳戶逐一核對完，再到「02 收現金、關帳」按「關帳並印關帳單」。關帳不會要你重填一輪點鈔、實收或原因，只檢查上方的核對結果，通過就直接確認關帳。

1. **先看當日營收**：確認日期、品牌、訂單總額。作廢不計；折扣後的訂單營收不會因核對填的數字而改動。
2. **01 核對帳戶**：開帳中品牌的每個帳戶（現金、LINE Pay、信用卡、轉帳與其他）各按一次「核對」，填實收；應收≠實收時填差異原因，按「確認」。全部確認後，卡片顯示「N/N 已確認」。各帳戶怎麼核對見下節。
3. **02 收現金、關帳**：按「關帳並印關帳單」。系統只檢查：
   - 上方每個帳戶都已核對，且差額為 0 或已填原因。還有沒核對的帳戶時會列出名稱（「還沒核對：…。先到上方按『核對』。」），關帳鍵不能按。
   - 沒有未清的桌。還有桌開著，要先結帳清桌。
   - 點鈔（現金核對的實收）不少於零用金。
4. 檢查通過後，畫面直接顯示「放保險箱（現金營收）」與「放錢櫃（零用金）」金額。訂單總額與帳戶總額不同時只提示差額，不必再填總差異原因（各帳戶原因已在核對時填過），也不會擋關帳。
5. 按「關帳並印關帳單」，依序確認兩個提示（現金分配；訂單總額與帳戶總額），再輸入員工 PIN，即完成關帳並列印關帳單。關帳人記為輸入 PIN 的員工。
6. **03 收零用金**：關帳後按「印零用金單」，零用金＋零用金單＋發票憑證一起放錢櫃。

帳戶總額＝現金實收＋各非現金帳戶實收。現金實收＝點鈔－開帳零用金－臨時收入＋臨時支出，並不是整個錢櫃金額。即使個別差異正負互抵、總額相同，各帳戶差異原因也不能省略。本次日結須取出所有零用金，留存金固定為 0。

## 各帳戶核對（01 核對帳戶）

日結頁「開關帳」上方列出開帳中品牌的每個帳戶，各有一顆「核對」按鈕，按下開啟核對視窗：

- **現金**：按「核對」會先要員工 PIN 開錢櫃（留稽核紀錄；開錢櫃失敗不擋點鈔），再開視窗。應收＝應有現金（零用金＋現金營收＋臨時收入－臨時支出）；實收按面額填張數或直接填總額。
- **LINE Pay、信用卡（中信）**：實收自動帶入後台同步結果（依開關帳時間歸屬本店別），可修改；尚未同步或有新交易時，在視窗內按「同步 LINE Pay」／「同步 中信刷卡」再帶入。視窗內的「帳務參考：… 逐筆實收與對帳」可展開看逐筆明細與匯出 CSV。
- **轉帳與其他**：實收預設等於應收，帳對了直接按確認；不同則對照收單機、商家後台或交接資料改填。沒有收款填 `0`。啟用的自訂收款帳戶、當天有營收的停用帳戶也會列出。

應收≠實收時必須填差異原因才能按「確認」。要改已確認的帳戶，再按一次該列（「✓ 已確認」）重新核對。核對結果在關帳前不寫入帳務，按「關帳並印關帳單」時才連同點鈔面額、各帳戶實收與原因一起送出。核對進度存在這台平板（各品牌分開、18 小時失效），頁面自動重整或重新載入後，會還原仍開帳中帳本的核對結果與核對到一半的視窗；換一台裝置不會帶過去。關帳成功後清除該帳本的核對結果。

核對完成後若營收或帳戶又有變動（新結帳、作廢、臨時收支等），關帳會被拒絕並提示「營收或帳戶已變更，請重新載入日結並逐項確認」；請重新載入，對金額有變動的帳戶再按一次「核對」。

## 帳務參考與營業時間外收款

- LINE Pay 與中信刷卡的逐筆實收、店別歸屬、分店明細與 CSV 放在各自的核對視窗內。帳本已關帳或沒開帳的日子沒有核對鍵，才在頁底保留「帳務參考（LINE Pay／中信逐筆實收）」收合區查歷史。
- 兩者都只有一個商店帳號，依當天開關帳時間歸屬店別（2026-10-29 起中信自動對帳取代台新手填）。實收以退款扣除後、手續費扣除前核對。
- 「營業時間外收款」列出發生時沒有任何一本帳開著的交易，是本店收的可按「歸到本店」；別店開帳時段收的交易收合在下方，改歸本店須選原因。按錯可以撤回。改歸後再核對該帳戶。
- 全店參考數字不會自動視為本品牌已核對。

## 既有功能與歷史紀錄

- 開帳、零用金承接、臨時收支、小結點驗、印小結單、管理員重開補單均保留。小結點驗只核對抽屜現金、不關帳，與上方帳戶核對分開。
- 新關帳單會保存並列印各帳戶 POS／實收／差額／原因，以及訂單總額、帳戶總額、總差異（有總差異原因才列出）。重印使用關帳當時凍結的 JSON，不重算。
- 舊關帳單仍能重印，但不補造舊資料沒有的確認與原因。
- 舊版客戶端只送現金的關帳請求會被拒絕；請重新載入 POS 頁面。

## 驗證

```sh
node --test scripts/test-*.mjs
CHROME_PATH=/path/to/chrome node scripts/smoke-pos-daily-close.mjs
CHROME_PATH=/path/to/chrome node scripts/smoke-pos-account-confirm.mjs
```

瀏覽器 smoke 使用固定的本機模擬資料，實際執行核對視窗、關帳前檢查、送出 payload、純邏輯驗證與列印 HTML；不會呼叫正式環境或建立財務紀錄。正式環境僅以 GET 與部署映像版本驗證；實際帳務入庫、機台實收及紙本列印仍須現場操作驗收。
