# 後台全頁點擊模擬檢查

更新：2026-09-15。方法：本機 `localhost:8090`（隔離資料庫 `emoji_admin_ui_test`），以 Claude in Chrome 實際操作每個後台分頁與活動工作區的每個面板；`confirm`／`prompt` 以自動同意覆寫以走完不可逆流程；每頁另讀 console 例外。角色涵蓋超級管理員、活動主（`/organizer`）、僅簽到人員（`/event-checkin.html`）。

## 已修（本次提交）

| 頁面 | 問題 | 修法 |
|---|---|---|
| 櫃檯、活動工作區 | 「開通會籍」「發點」「刪除活動」按下後無反應；console `ReferenceError: doThen is not defined`（`doThen` 只宣告在 `bind()` 內） | `doThen` 提升為全域；刪除活動後先回清單再重整，不再多跳「找不到這場活動」 |
| 廣告總覽 | 「＋新增投放」空白直接按「新增」會建立空投放 | 關聯貼文、起訖日期必填，結束不可早於開始 |
| 操作紀錄 | 路徑顯示 `/api/admin/api/admin/...`（`res.on('finish')` 時 `req.path` 已還原完整路徑） | `server.js` 改記 `req.originalUrl`；前端對舊資料去重前綴；新增即時篩選框與筆數 |
| 總覽 | 只有 KPI 與說明文，看不到今天要處理什麼 | 新增「今日待辦」：待審場地申請、待入帳會費、7 天內活動（含報名／已到，直達工作區） |
| 會員 | 發點要手打 user id | 每列「發點」鈕自動帶入並聚焦點數欄 |
| 參與紀錄、最新消息、權限管理 | 確認入帳、刪除消息、切換管理員／活動主都沒有 confirm | 補上含對象與後果的確認 |
| 活動名單 | 核准、拒絕、變更狀態、贈票、改票種、移除票完成後無任何回饋 | 各動作完成 toast |
| 活動匯入來賓 | 結果只寫「更新票種 0 位，跳過 0 位」 | 改為「新增 N 位、更新票種 N 位、跳過 N 位」＋ toast |
| 活動票種 | 儲存後票種標題仍顯示「新票種」 | 儲存後以伺服器回傳重繪 |
| 活動分享連結 | 報名連結欄約 180px 寬、URL 不可讀 | 全寬等寬字型 |
| 活動操作紀錄／來賓紀錄 | `embed_updated`、`message_drafted`、`guest_imported:registered` 等原始代碼 | 補標籤；`動作:狀態` 格式自動翻成「主辦人匯入來賓（已報名）」 |
| 活動取消 | 取消後工作區標頭徽章仍是舊狀態 | 同步標頭 |
| 行事曆 | 活動只連到清單；已取消活動仍以一般樣式顯示 | 直達該活動工作區；已取消加刪除線並標示 |
| 場地申請 | 新申請送出後切回分頁不會重新載入 | 每次進入分頁重新載入（草稿保留） |
| 菜單 | 「店別」欄折成兩行；未存檔狀態只靠一閃即逝的 toast | 欄位不換行；有未儲存變更時「儲存至伺服器」鈕變色並標示 |
| 活動清單 | 0 場時同時出現篩選空狀態與表格空狀態 | 無資料時只留表格空狀態 |
| 活動主入口 | 簽到人員登入顯示「暫時無法連線」 | 改為說明無活動主權限並指引改用現場簽到入口 |
