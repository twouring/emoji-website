02

標誌 · Logo

山丘般的書頁包住「～」的圖形標（透空，跟隨背景色），搭配 Rest Book 手寫英文字標與節制斷筆的「約書旅」中文字標，由上而下為圖形 → 英文 → 中文。字標皆為外框定稿，內文寫法固定為 Rest Book（R、B 大寫，中間一個空格）。

05

使用原則 · Usage

約書旅依《約書旅 Rest Book 品牌識別手冊 CIS 1.0》（2026-11-04）。以下為摘要，完整規範見原始檔。

維持原比例

不拉伸、壓扁、傾斜，不加陰影、描邊、漸層或立體效果。

三種配色

霧苔綠、暖墨單色、紙白反白（放在霧苔綠或暖墨實色底）。書頁與「～」的透空區不填白。

安全距離

四周至少保留 x＝「約」字高的 ½；單獨圖形四周至少保留其高度的 ¼。

最小尺寸

直式主標 240 px／40 mm、橫式 320 px／55 mm、圖形＋中文 160 px／28 mm、單獨圖形 32 px／8 mm。再小就換圖形版。

不重打字標

手寫英文與斷筆中文是外框定稿，不補筆、不填斷口、不用字型重打。

不借母品牌黃

不放黃底、不混用其他品牌色，也不跨在嘈雜照片上。

角色 moji · 休憩

站著也能睡。席位牌、淋浴間標示、安靜區標示。約書旅的店內物件可以用 moji 的這個狀態；moji 用墨色線，不換成品牌色。
