サブブランドはマスターブランドに代わるものではありません。対外文書、名刺、看板、公式サイトには、マスターブランドの名称かロゴを少なくとも一度入れます。2つのロゴを並べるときは 1px の線か余白で区切り、新しいロックアップは作りません。

02

ロゴ · Logo

山なりのページが「～」を包むシンボル（抜きで背景色に従う）に、手書きの Rest Book 英字ロゴタイプと、控えめな筆の切れを持つ「約書旅」の漢字ロゴタイプを、シンボル → 英字 → 漢字の順に組みます。ロゴタイプはアウトライン化済みで、本文では常に Rest Book（R と B は大文字、間にスペース1つ）と表記します。

03

カラー · Color

サブブランドのブランドカラーは各1色で、マスターブランドの紙色と墨色と組み合わせます。言文字の黄色（#FFDE34）はマスターブランド専用で、サブブランドのロゴやカラー面には使いません。

HEX／RGB は画面用の基準値です。CMYK 約 16 · 0 · 10 · 51 は一般的な換算の参考値で、Pantone の指定はありません。ミストモスと紙色のコントラストは 4.27 : 1 で、ロゴ、図形、大きな文字に使い、小さな本文には使いません。印刷前に用紙に合わせて色校正してください。

05

使用ルール · Usage

約書旅は『約書旅 Rest Book ブランドアイデンティティ・マニュアル CIS 1.0』（2026-11-04）に従います。以下は要約で、詳細は元データを参照してください。

比率を変えない

伸ばす、つぶす、傾けることはしません。影、フチ取り、グラデーション、立体効果も付けません。

配色は3種類

ミストモス、墨一色、紙白の白抜き（ミストモスか墨のベタ地の上）。ページと「～」の抜きは白で埋めません。

余白

周囲に x 以上（x＝「約」の字高の ½）。シンボル単体は高さの ¼ 以上。

最小サイズ

縦型 240 px／40 mm、横型 320 px／55 mm、シンボル＋漢字 160 px／28 mm、シンボルのみ 32 px／8 mm。これより小さいときはシンボル版に。

ロゴタイプを打ち直さない

手書きの英字と筆の切れのある漢字はアウトライン化済み。筆を足す、切れを埋める、フォントで打ち直すことはしません。

マスターブランドの黄色を使わない

黄色の地に置かず、ほかのブランドカラーと混ぜず、騒がしい写真の上にも置きません。

キャラクター moji · ひと休み

立ったままでも眠れる。座席札、シャワー室の表示、静かなエリアの表示。約書旅の店内アイテムには、moji のこのポーズを使えます。moji は墨色の線で描き、ブランドカラーには変えません。
